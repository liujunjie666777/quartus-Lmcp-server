# Intel IP Co-Simulation

Use this skill when plain RTL simulation is not enough. The MCP `run_simulation` tool already compiles Quartus sim libraries and scans IP setup scripts.

## Required MCP Tools

- `get_quartus_installation`
- `get_project_info`
- `list_project_files`
- `read_qsf`
- `compile_project`
- `get_compilation_messages`
- `create_testbench`
- `add_simulation_file`
- `run_simulation`
- `read_simulation_log`
- `list_simulation_artifacts`

## Workflow

1. Confirm Quartus and ModelSim discovery with `get_quartus_installation`.
2. Read `get_project_info`, `list_project_files`, and `read_qsf`; note family, device, top entity, and registered IP-generated files.
3. If the IP was generated by Quartus, make sure project files exist before simulation. Run `compile_project` with `map` when generation/elaboration status is uncertain.
4. Create or register a testbench through `create_testbench` or `add_simulation_file`.
5. Run `run_simulation` with defaults: `include_intel_libraries=True`, `use_ip_setup_scripts=True`, and `include_project_files=True`.
6. Use `generate_eda_netlist=True` only when the user specifically needs Quartus-generated EDA simulation output or a gate/netlist-style run.
7. Inspect `read_simulation_log` for missing libraries, unresolved modules, license errors, and pass markers.
8. List artifacts with `list_simulation_artifacts` and report which Intel libraries were compiled.

## Co-Sim Checks

- Expected library families include `lpm`, `sgate`, `altera_mf`, `altera_lnsim`, `altera_primitives`, and the device family atoms library such as `cycloneive`.
- Missing `lpm_counter`, `altsyncram`, PLL, FIFO, or device atom modules usually means the Intel sim libraries were skipped, not that the RTL is wrong.
- IP setup scripts are usually named `mentor/msim_setup.tcl`; let the MCP tool scan them before writing custom ModelSim commands.
- ModelSim license failures are environment issues. Report them directly instead of rewriting HDL.

## Output Contract

Return the family, testbench top, Intel libraries loaded, IP setup scripts discovered or absent, pass/fail evidence, unresolved modules, and next fix.
